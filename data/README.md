# data/

ไม่ commit ข้อมูลลง git — ดาวน์โหลดเองตามนี้

- `raw/` — Thai Wikipedia dump (`thwiki-latest-pages-articles.xml.bz2`)
- `processed/` — ข้อความที่ทำความสะอาดและตัดคำแล้ว, คลังศัพท์
- `eval/` — TH-WordSim-353, TH-SimLex-999 (Netisopakul et al., 2019)
- wisesight_sentiment โหลดผ่าน `datasets` (`pythainlp/wisesight_sentiment`)
