# Demo (หน้าเว็บแบบไฟล์เดียว)

หน้าเว็บสองหน้านี้ฝังผลจากโมเดลที่เทรนแล้วไว้ในไฟล์ เปิดได้โดยไม่ต้องรันโค้ดหรือมีโมเดลในเครื่อง

| ไฟล์ | เนื้อหา |
|---|---|
| `index.html` | คุยกับแมลงวัน: พิมพ์ข้อความ แล้ว FlyVec ตอบด้วยคำที่เซลล์ติดไฟตรงกันมากที่สุด และประโยคจาก Thai Wikipedia ที่ใกล้ที่สุด |
| `words.html` | พิมพ์คำ แล้วเทียบคำใกล้เคียงของ FlyVec กับ word2vec พร้อมแผง Kenyon cells 400 เซลล์ (k = 4, 8, 16, 32, 64) |

ข้อมูลในหน้าเว็บมาจากโมเดลที่เทรนใหม่ด้วยการตั้งค่าเดียวกับการทดลองหลัก (w = 11, seed 0, learning rate 0.3, Thai Wikipedia 10 ล้านโทเคน, คลังศัพท์ 20,000 คำ) ไม่ใช่ไฟล์โมเดลชุดเดียวกับที่ใช้ทำ `results/`

ข้อจำกัดของหน้าแชต

- FlyVec แต่งประโยคไม่ได้ ข้อความตอบเป็นแม่แบบตายตัว รวมกับคำและประโยคที่เลือกจากรหัส FlyVec ไม่มีโมเดลภาษาอื่นช่วยตอบ
- ตัดคำด้วยการจับคำยาวที่สุดในคลังศัพท์ ไม่ใช่ PyThaiNLP จึงอาจตัดต่างจาก pipeline หลัก
- วิธีเลือกประโยคเป็นของ demo นี้เท่านั้น ไม่ได้อยู่ในการประเมินผลของรายงาน
